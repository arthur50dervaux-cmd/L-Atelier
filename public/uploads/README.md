# Fichiers téléversés depuis l'administration

Les images, vidéos et maquettes envoyées via l'interface d'administration
(`/admin.html` → bouton « Téléverser ») sont committées ici lors de la
publication. Vous pouvez aussi y déposer des fichiers à la main et les
référencer dans l'admin avec le chemin `uploads/mon-fichier.jpg`.
