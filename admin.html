Publier le site

La publication enregistre vos modifications dans le dépôt GitHub du site ; le site se redéploie automatiquement en une à deux minutes.

Créez un jeton « fine-grained » sur GitHub (Settings → Developer settings → Personal access tokens) limité à ce dépôt, avec la seule permission Contents : Read and write. Ne partagez jamais ce jeton : c'est la véritable clé du site.
